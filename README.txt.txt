CH45 COMBAT DEMO

Project Overview

CH45 Combat Demo is a 3D combat game prototype developed using Unity.

This project demonstrates character movement, jumping, combat animations, enemy damage, health systems, and enemy death animations.

Engine

- Unity

Features

- Character Movement (WASD)
- Jump System
- Attack Animation
- Enemy Health and Damage System
- Health Bar
- Enemy Hit Reaction
- Enemy Death Animation
